# 랜드랭귀지 회사소개서

> 공인중개사·시행사 대상 부동산 콘텐츠·데이터 마케팅 대행 | 2026년 8월 기준

---

## 1. 회사 개요

| 항목 | 내용 |
| --- | --- |
| 상호 | 랜드랭귀지 |
| 설립 | 2023년 5월 |
| 인원 | 6명 (대표 1 · 콘텐츠기획 2 · 데이터분석 2 · 디자인 1) |
| 소재지 | 서울 동작구 노량진로 (본사) |
| 사업분야 | 부동산 중개업소·시행사 대상 블로그 콘텐츠, 시세 리포트, 데이터 대시보드 제작 |
| 수행 이력 | 서울 권역 중개업소 9곳, 누적 콘텐츠 1,100건 이상 |

"땅(Land)의 정보를 사람의 언어(Language)로 옮긴다"는 이름 그대로, 실거래가·시세 같은 원자료를 중개업소 고객이 이해할 수 있는 콘텐츠로 바꾸는 일에 집중합니다. 분양 마케팅이나 광고 대행은 다루지 않고, 블로그·리포트·대시보드 등 콘텐츠·데이터 기반 마케팅만 수행합니다. 인원을 늘리기보다 담당자가 거래처를 끝까지 관리하는 구조를 유지하며, 기획 인력 1인당 동시 담당 거래처는 4곳으로 제한합니다.

---

## 2. 주요 실적

**홍길동 공인중개사사무소 (서울 동작구 노량진동, 2025.03~진행 중)**

- 서비스: 블로그 콘텐츠 제작(월 8건), 동 단위 아파트 시세 대시보드(분기 1회)
- 기간: 5개월 차 진행 중
- 결과
  - 블로그 월 유입: 320명 → 1,850명
  - 네이버 검색 상위(1페이지) 노출 키워드: 12개
  - 월 평균 상담 문의: 4건 → 17건
- 첫 2개월은 유입 변화가 크지 않았으며, 3개월 차부터 지역 키워드 재설정 후 유입이 늘었습니다.

*그 외 거래처 실적은 비밀유지 조항에 따라 요약 수치만 제공하며, 상세 자료는 신규 상담 시 익명 처리하여 열람 가능합니다.*

---

## 3. 서비스 4종

1. **블로그 콘텐츠 제작** — 네이버 상위노출 기준에 맞춘 매물·지역 정보 포스팅, 월 8건 기준
2. **주간 시세 리포트** — 자치구 단위 아파트 실거래가·가격지수·입지분석을 담은 1~2페이지 리포트
3. **동 단위 아파트 대시보드** — 특정 동의 실거래가를 인터랙티브 웹페이지로 정리해 고객 상담용으로 제공
4. **SNS·랜딩페이지 운영** — 블로그와 연동한 인스타그램 채널 운영, 매물 소개 랜딩페이지 제작

서비스별 상세 범위와 비용은 [service-policy.md](service-policy.md)를 참고해 주십시오.

---

## 4. 차별점

- **공공데이터 기반** — 국토교통부 실거래가 공개시스템 등 공개된 원자료를 사용하며, 가공 과정과 출처를 리포트에 함께 표기합니다.
- **소수 인원 직접 운영** — 외주 없이 6명이 기획부터 발행까지 직접 처리하여, 거래처별 매물 특성과 상담 이력을 담당자가 계속 파악합니다.
- **순위·문의 건수를 보장하지 않습니다** — 검색 노출 순위나 상담 문의 증가는 콘텐츠 품질 외에도 지역 경쟁 상황에 영향을 받으므로, 특정 수치를 약속하지 않고 매월 실적을 있는 그대로 보고합니다.

| 단계 | 기간 | 주요 활동 |

| 5. 계약 갱신 검토 | 계약 종료 4주 전 | 성과 리뷰 후 연장·조정 여부 협의 |
